# 📁 Custom PDF Storage Folder

Upload your custom PDF files (for **CUET**, **JEE**, or **IAT & NEST**) into this `pdfs/` folder!

### 🔗 How to get your Direct Raw PDF URL for Admin Panel:

Once you upload any PDF file (e.g. `cuet_chemistry_notes.pdf`) into this folder on GitHub:

Your Direct PDF URL will be:
`https://raw.githubusercontent.com/piyushsingh15507-dev/pdf-portal/main/pdfs/YOUR_FILE_NAME.pdf`

---

### 📝 Example Usage:
- File uploaded: `cuet_chemistry_ch1.pdf`
- Direct Link to paste in Admin Panel:
  `https://raw.githubusercontent.com/piyushsingh15507-dev/pdf-portal/main/pdfs/cuet_chemistry_ch1.pdf`
