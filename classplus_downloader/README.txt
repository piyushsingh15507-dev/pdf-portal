==================================================
 CLASSPLUS DEDICATED VIDEO & PDF DOWNLOADER
==================================================

HOW TO RUN:
1. Make sure Python 3.x is installed (pip install pycryptodome).
2. Double click 'Run_Downloader.bat' (or run 'python downloader_server.py' in cmd).
3. Open your browser and go to: http://127.0.0.1:8500

HOW TO USE:
1. Paste your Classplus Access Token (x-access-token) in the Token field.
2. Paste Video Link or Content ID (U2FsdGVk...) in the Link field.
3. Click 'Fetch Info', select 720p/480p quality, and click 'Download & Decrypt'.
